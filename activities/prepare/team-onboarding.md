## Team onboarding

Walk a new joiner through project-specific context on a path shaped by their role, ending at a recorded ready-to-take-a-ticket checkpoint. It reads the whole knowledge base and produces an onboarding record. It is also that knowledge base's own test harness: if someone cannot reach first-ticket-ready without a human explaining things verbally, the knowledge base is not real yet.

**Owner:** Delivery Manager
**Engagement(s):** Greenfield / Brownfield conversion / Build and Extend / AMS & Run
**Status:** In progress

## Uses

- **skill:** onboarding-guide
- **mcp:** jira
- **artifact:** onboarding-record
- **knowledge:** reads all nine buckets
- **q-gate:** prepare→explore
