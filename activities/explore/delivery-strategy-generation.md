## Delivery strategy generation (Cutover, Training, Testing, Convention)

Generate the non-technical delivery-strategy documents — Cutover, Training, Testing, and
Convention — from project scope and context (fit-gap analysis, object mapping, or other
scope inputs where available), noting cross-strategy dependencies such as Cutover <-> Testing.
Deliberately excludes technical architecture strategies (Integration, Extensibility, Security,
Data, Landscape, Release & Transport, Output/UX, Operations, Infrastructure, Toolchain), which
belong to the separate SAD / Technical Architecture track. Feeds the Cutover dependency-check
activity once its own strategy is approved.

**Owner:** Delivery Manager
**Engagement(s):** Greenfield / Brownfield conversion / Build and Extend
**Status:** In progress
