## Factory onboarding

User entry for a consultant who installed the factory: orient the tool path,
verify skills and required connectors, capture engagement context, then route to
one first delivery skill with an explicit handoff. Meta for the user, not a
client deliverable; produces no gate evidence by itself.

**Owner:** Delivery Manager
**Engagement(s):** Greenfield / Brownfield conversion / Build and Extend / AMS & Run
**Status:** In progress

## Uses

- **skill:** factory-onboard
- **knowledge:** standards, domain-packs, methodology

## Handoff output

For `day-0 setup` and `start project work`, return the tool, skills-visible
status, workspace path, phase, engagement, goal, next skill, required inputs,
connector gaps and write mode. Project work also writes a local:

```text
workspace/factory-onboard/<date>-<slug>/context.json
```
