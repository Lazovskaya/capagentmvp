## Stable entry points (safe to link as-is)

- [SAP Help Portal](https://help.sap.com) — Clean Core methodology, extensibility guidelines
  (in-app vs. side-by-side), ABAP Test Cockpit documentation.
- [SAP Support Portal / Notes & KBA search](https://support.sap.com/en/my-support/knowledge-base.html) —
  look up SAP Note 2913617 (ATC data collection) and 1912445 (custom code migration) here.
- [SAP Community](https://community.sap.com) — practitioner guidance on Clean Core scoring and
  custom-code remediation patterns.
- [SAP Business Technology Platform](https://www.sap.com/products/technology-platform.html) —
  entry point for side-by-side/RAP-based extensibility, relevant once ATC results define real
  extension scope.
