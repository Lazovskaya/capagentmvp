## Sizing analysis

Turn a raw SAP sizing input — a Readiness Check sizing chapter, a HANA Sizing Report, a Quick
Sizer export, or a RISE FUE/user count — into an actual sizing recommendation: growth buffer
applied, archiving offset applied, split per target instance, with any RISE T-shirt/technical-data
mismatch flagged explicitly. Raw sizing-tool output is a baseline, not a provisioning target.
