## Defect triage

Read the defect queue, decide for each item whether it is a bug or a functional spec flaw, route it to the right role, and recommend a fix. The classification is commercial rather than technical: a bug is fixed under the fee, a spec flaw is a change request. So the agent recommends and a named human confirms, and the verdict records who. This only works if the traceability chain upstream is complete.
