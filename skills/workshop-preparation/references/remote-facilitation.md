# Remote Fit-to-Standard Workshop Facilitation Guide

*Source: SAP Activate Methodology Accelerator S4H_730 (September 2022)*

Applies when one or more participants join the workshop remotely. Also apply when running a fully remote engagement.

---

## Participant limits

**Maximum 8 Business Process Experts per workshop session.** More than 8 reduces engagement and decision velocity. Split into parallel streams if the scope requires it.

---

## Pre-workshop: Preparation checklist

### Participants (BPE / CE / PM)

**Video conferencing:**
- Install the video conferencing software used by the project
- Set up microphone and camera access
- Use headphones — computer speaker causes echo for others
- Test connectivity with a colleague before Day 1
- Know how to mute/unmute

**Collaboration tools:**
- Install collaboration software (project manager provides access)
- Verify access to shared folders

**Environment:**
- Second monitor + physical keyboard recommended for long sessions
- Dedicated quiet room or space
- Ergonomic chair — sessions run 6–7 hours

### Configuration Expert (CE)

- Plan for **more time per scope item** than in an onsite workshop
- Run a **proof-of-concept session** with BPEs ahead of Day 1 (tool access, audio/video, Starter System)
- Test all tools: video, camera, audio, customer Starter System
- Prepare pulse-check questions (Mentimeter or Qualtrics) to use throughout

### Project Lead

- Define and share the collaboration tool stack (what tool, what purpose, where to find it)
- Outline workshop etiquette and Golden Rules before Day 1
- Provide templates in the shared folder before the workshop starts

---

## Pre-kickoff execution checklist (Day 1, first 5 minutes)

Ask every participant to confirm:

- [ ] Email, browser, and disruptive apps are closed
- [ ] Drink/water available (long sessions)
- [ ] Notepad or notes app ready
- [ ] Desktop ready for screen sharing if needed
- [ ] Can hear audio and see shared screen clearly (if bandwidth is low, dial in via phone)
- [ ] In a quiet space; if not, will use mute when not speaking

## Time-boxing rules

| Rule | Value |
|---|---|
| Break every N minutes | 5-minute break every **45 minutes** |
| Gap between workshops | **15 minutes** — allows information processing before next topic |
| Daily wrap-up | 30 minutes at end of each day (PM + CE + all BPEs) |
| Weekly status meeting | 1 hour — PM, CE, BPE leads review status and open actions |

### Sample day structure

## Role-specific execution rules

### Project Lead
- Invite only decision-takers as BPEs — not observers
- Reinforce tool governance: which tool, what for, where to find it
- Establish shared folder naming that maps to the workshop schedule
- Enact a backup plan if the collaboration tool is unavailable

### Configuration Expert
- Share goals and desired outcomes in the digital board at the start; review mid-session and end of session
- Alternate presentation with a co-lead when possible to sustain attention
- Request BPE contributions **by name** (nominate who speaks next)
- Build pauses into presentation — do not deliver monologues
- **Together-alone technique**: give BPEs individual reflection time before opening group discussion
- Assign a co-lead to manage chat, backlog, and digital board — CE should not multitask this
- Check alignment with BPEs every 15 minutes

### Business Process Expert
- Camera on during introductions, when speaking, and end-of-session Q&A
- Keep mic unmuted wherever possible to encourage natural conversation
- Announce in chat when stepping away; announce return
- Close email and distracting apps before the session
- Use digital board stickers for collaborative brainstorming and parking lot items
- Follow the CE's steps in the system when possible (active participation, not passive viewing)

## Recommended tool stack

| Purpose | Tool |
|---|---|
| Video conferencing + document storage | Microsoft Teams |
| Virtual whiteboard / collaborative brainstorming | MURAL |
| Delta requirements and backlog capture | SAP Cloud ALM or Backlog template |
| Pulse checks | Mentimeter or Qualtrics |
| Process flows and test scripts reference | SAP Best Practices Explorer |
| Roadmaps | SAP Roadmap Viewer |
| Workshop demo | SAP S/4HANA Starter System |
