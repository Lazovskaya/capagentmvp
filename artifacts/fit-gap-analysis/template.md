## Review checklist

- [ ] Every source Row ID appears once.
- [ ] Gap items cite the exact FTS Row ID and named Delta owner.
- [ ] Every Gap has a Gap Type assigned — determines which artifact is required next.
- [ ] Business Justification and Business Impact are populated for all Extension / Custom Dev gaps.
- [ ] MoSCoW priority assigned for all gaps going to Delta Design Workshop.
- [ ] Workaround rows are unresolved/TBC unless a Live decision log records their resolution.
- [ ] Unmapped application coverage is visible as an open question, not silently treated as a Gap.
- [ ] No technical extensibility tier is selected here — that is `solution-design`'s decision.
